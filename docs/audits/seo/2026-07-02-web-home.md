# SEO Denetim Raporu — apps/web home (Faz 8 doğrulama turu)

**Tarih:** 2026-07-02  **Denetçi:** seo-specialist (salt-okunur)  **Verdict:** PASS_WITH_RISKS

Kapsam: `apps/web` home sayfası + global SEO altyapısı (`layout.tsx`, `page.tsx`,
`robots.ts`, `sitemap.ts`, `next.config.ts`). İskelet fazı: tek sayfa +
placeholder içerik; gerçek ürün/kategori sayfası henüz yok.

## Bulgular (önem sıralı)

### [CRITICAL] Canonical/OG/sitemap URL'leri env yoksa build'de localhost'a sabitleniyor
- **Konum:** `apps/web/app/layout.tsx:5,8,15,20` · `apps/web/app/sitemap.ts:3,8` · `apps/web/app/robots.ts:3,8`
- **Sorun:** `NEXT_PUBLIC_SITE_URL` tanımsızken `?? "http://localhost:3000"`
  fallback'i devreye giriyor. Build çıktısıyla kanıtlı: `.next/server/app/index.html`
  → `<link rel="canonical" href="http://localhost:3000"/>`,
  `.next/server/app/sitemap.xml.body` → `<loc>http://localhost:3000</loc>`.
  Tüm route'lar `○ (Static)` prerender — URL'ler build anında donuyor. Değişkeni
  zorunlu kılan mekanizma yok: `apps/web/.env.example` yok, `turbo.json` build
  task'ında `env` alanı yok (ayrıca cache-correctness sorunu), CI workflow yok.
  Prod pipeline değişkeni unutursa site canonical/sitemap olarak ulaşılamaz
  localhost yayınlar → tek sayfalık sitede index kaybı.
- **Düzeltme:** (1) `apps/web/.env.example` → `NEXT_PUBLIC_SITE_URL=https://example.com`;
  (2) `turbo.json` → `tasks.build.env: ["NEXT_PUBLIC_SITE_URL"]`;
  (3) production build'de değişken eksikse `throw` (localhost fallback yalnız dev/test).

### [HIGH] OG image ve Twitter Card meta verisi tanımlı değil
- **Konum:** `apps/web/app/layout.tsx:16-23`
- **Sorun:** `openGraph.images` yok, `twitter` alanı hiç yok (Next.js twitter
  etiketlerini OG'den türetmez) → sosyal paylaşımlarda önizleme kartı çıkmıyor.
- **Düzeltme:** 1200×630 varsayılan OG görseli + `metadata.twitter = { card:
  "summary_large_image", ... }` (layout seviyesinde fallback).

### [MEDIUM] Favicon / site icon dosyaları yok
- **Konum:** `apps/web/app/` (icon.png / favicon.ico / apple-icon.png yok)
- **Düzeltme:** App Router convention dosyalarını ekle; design-tokens marka rengiyle tutarlı.

### [MEDIUM] sitemap lastModified her build'de "şimdi"ye sabitleniyor
- **Konum:** `apps/web/app/sitemap.ts:9` (`new Date()`)
- **Sorun:** Kanıt: `<lastmod>2026-07-02T16:46:59.335Z</lastmod>`. Her deploy'da
  yanıltıcı "içerik güncellendi" sinyali → crawl-budget güveni azalır.
- **Düzeltme:** Gerçek içerik güncelleme tarihine bağla (env/const veya CMS `updatedAt`).

### [INFO] JSON-LD yok
- Placeholder sayfada somut şema tipi yok → ihlal değil, N/A (ileriye dönük listede).

## Verdict Gerekçesi ve Remediation

Temel SEO hijyeni doğru kurulmuş (statik prerender, minimal JS, doğru
title/description, tekil h1). Ancak CRITICAL bulgu yapısaldır: env guard +
`.env.example` + turbo env bildirimi eklenmeden production deploy YAPILAMAZ.
Kural gereği web feature'ı CRITICAL bulgu açıkken kapanamaz — bu bir doğrulama
turu olduğundan verdict PASS_WITH_RISKS; **remediation görevi** ilk web
feature'ının (veya ayrı bir hızlı fix turunun) task DAG'ına eklenmelidir:

> **Remediation (sahip: frontend-developer):** `apps/web/.env.example` oluştur,
> `turbo.json build.env`'e `NEXT_PUBLIC_SITE_URL` ekle, production'da eksik env
> için fail-fast guard yaz; ardından OG image + Twitter Card (HIGH) ve
> favicon/lastmod (MEDIUM) bulgularını kapat.
