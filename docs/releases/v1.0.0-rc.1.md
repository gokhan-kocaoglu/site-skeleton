## Faz 8.3 kapsamı

### PR-A — Stack yükseltme (HIGH-1)
Spring Boot 4.1 (ADR-0010 ACCEPTED) · Vite 8 (ADR-0013) · Next.js 16
(ADR-0014) · sürüm politikası "Active LTS/desteklenen hat" olarak netleşti
(ADR-0009).

### PR-B — Supply chain + Actions pinleme (HIGH-3, MEDIUM-6)
`supply-chain-trivy` job'u: repo + JAR taraması (`rootfs`, gömülü
`BOOT-INF/lib` dahil), HIGH/CRITICAL → FAIL, `ignore-unfixed` yok · CycloneDX
SBOM artifact + `assert-sbom.mjs` doğrulaması · `dependency-review` (PR'da,
`fail-on-severity: high`) · tüm harici `uses:` referansları tam 40-hex commit
SHA'ya pinli + exact release tag yorumlu (ADR-0015).

### PR-C — Gerçek `/new-project` sertifikasyonu (HIGH-2)
`projectSlug` kaydı ve idempotency (sayaç-tabanlı çıkarım kaldırıldı) ·
temiz-ağaç ön koşulu · plan-sonra-uygula atomikliği + tam rollback ·
deterministik memory üretimi ve iskelet vault'unun arşivlenmesi ·
mode-farkındalı yapısal kurallar · `bootstrap-e2e` job'u: geçici repoda gerçek
`--apply` ve **üretilen projenin kendi gate'i**.

### PR-D — Memory governance ve mühürler (HIGH-4, MEDIUM-2/3/4/5/7/8/9/10)
Merge-sonrası memory closure akışı + terminal closure PR istisnası ·
bayat-durum ve closure-bağlamı validator'ı (dal, dirty-path, merge-SHA
ancestry) · dış attestation sözleşmesi · verdict/disposition ayrımı · somut
handoff hedefleri ve genişletilmiş parser · authority map üç kolonlu semantik ·
shell memory/secret guard · recursive activation gate (üç sinyal) ·
kritik-domain %80 kapsam teli · formal task card zorunluluğu.

## Kabul edilmiş kalan riskler

- **Optional module hardening (BFF-1/2/3, MEDIUM):** `templates/admin-bff`
  rate limiting, Origin/CSRF ve CORS/şema doğrulaması olmadan gelir. Kayıtlı,
  sahipli ve aktivasyon-anı implementer'ına bağlıdır; `ACTIVATION.md` 12
  maddesi tamamlanmadan deploy yasaktır ve yapısal kapı bunu zorlar.
  Kanıt: `docs/audits/2026-07-03-baseline-security-review.md` (düzeltme
  şerhleriyle; doğru verdict **PASS_WITH_RISKS**).
- **Type-aware lint derinliği (ADR-0012):** benimseme kararı ilk gerçek proje
  başlangıcına bırakıldı.
- **Hook kapsamı:** hook'lar tam shell parser değildir (alias, encoding,
  dinamik eval, obfuscation kapsanmaz). Nihai güvenlik ağı CI'daki Gitleaks
  full-history taramasıdır — bilinçli, belgeli trade-off.

## Optional module activation sınırı

**Core skeleton production-ready baseline.** `templates/` altındaki modüller
(admin-bff · payments · e2e/Playwright · db SQL) build'e dahil DEĞİLDİR ve
"production-ready" iddiasının kapsamında yer almaz. Kopyalanıp etkinleştirilen
her modül, kendi `ACTIVATION.md` sertleştirme checklist'i tamamlanmadan
production'a çıkamaz; `verify-structure` `activationGates` kuralı `apps/**`
altında (dizin/paket adı veya `ADMIN_BFF_TEMPLATE_MARKER` imzasıyla, her
derinlikte) bunu teknik olarak zorlar.

Genel anlatımda **"tüm modülleriyle production-ready" ifadesi kullanılmaz.**

Bu kapsam sınırı, üçüncü denetimin **MEDIUM-1** maddesinin kapanış kanıtıdır
(provenance: `docs/source-briefs/faz-8-3-medium-1-provenance-addendum.md`).

## RC1 yayınlama ön koşulları (snapshot yazıldığında karşılanmamıştı)

1. **PR #30** gerçek merge commit ile merge edilir → `FINAL_EVIDENCE_MERGE_SHA`.
2. PR #30 **post-merge main CI** yeşil olur →
   `FINAL_EVIDENCE_POST_MERGE_CI_RUN_URL`.
3. PR #30 için **terminal memory closure PR**'ı merge edilir →
   `FINAL_EVIDENCE_CLOSURE_PR` + `FINAL_EVIDENCE_CLOSURE_MERGE_SHA`.
4. Closure sonrası **main CI** yeşil olur →
   `FINAL_EVIDENCE_CLOSURE_POST_MERGE_CI_RUN_URL`.
5. Kullanıcı `RELEASE_DECISION` verir.
6. Placeholder'lar **GitHub Release oluşturma ekranında** gerçek değerlerle
   doldurulur; `RC1_RELEASE_TARGET_SHA` = adım 3'ün closure merge SHA'sı.

**Bu placeholder'ları doldurmak için yeni bir repository PR'ı açılmaz.**
Değerler dış immutable GitHub Release üzerinde mühürlenir — aksi hâlde her
release yeni bir kanıt PR'ı, o da yeni bir memory closure gerektirir ve zincir
hiç kapanmaz.

Altı adım tamamlanmadan bu taslak yayınlanmayacaktı; adımlar tamamlandı ve
external immutable release yayımlandı.
