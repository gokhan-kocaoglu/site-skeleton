- **Üç authority sınıfı**: historical (grammar-only, değişmez), current (canonicalVersion
  manifest field), proposed (release-time core eşitliği policy-driven).
- **Exact 6-key şema `upstreamReleaseVersionPolicy`**:
  - `upstreamReleaseVersionPolicy.canonicalVersion` (string, örnek: "1.0.0")
  - `upstreamReleaseVersionPolicy.tagPrefix` (string, örnek: "v")
  - `upstreamReleaseVersionPolicy.prereleaseChannels` (array, örnek: ["rc"])
  - `upstreamReleaseVersionPolicy.generatedProjectScope` (enum: upstream-only | project-wide)
  - (JSON schema garantisi: tam 6 anahtar)
- **Dar grammar**: build metadata yasak · leading zero yasak · whitespace yasak ·
  SemVer tam iddası YOK · yeni bağımlılık/paketi eklenmiş YOK.
- **Manifest bounded blok** (F4-MEDIUM-04 sınıfından bağışık): `docs/releases/README.md`
  blok 7 satır exact string eşitliği validator tarafından doğrulanır.

  dokuman'ın step 7'si manuel bağlantı kontrol listesidir, makine tarafından

- **Generated-project kontaminasyonsuzluğu**: generatedProjectScope upstream-only
  ise generated dosyalardaki 0.1.0 / 0.1.0-SNAPSHOT korunur, policy deep-equal taşınır.
