## Tasarım Kararı

ADR-0019 (`docs/adr/ADR-0019-web-security-headers.md`) şu kararları sabitledi:

- **Model B mimarisi**: Next.js runtime enforcement + provider-neutral
  static-host/edge contract.
- **Üç bağımsız oracle**: literal contract testleri (positional)·
  static document block-equality (fail-closed)· build-artifact oracle
  (deterministic).
- **Blok eşitliği F4-MEDIUM-04 sınıfına bağışıktır**: doküman katmanı hiçbir
  satırı ayrıştırmaz; bounded blok tek bir exact string olarak
  karşılaştırılır. Bu yüzden `*` / `+` / `1.` / girinti / boşluk
  sürüklenmesi tanım gereği mismatch üretir ve `verify-structure`'ın bullet
  grameri açığı (F4-MEDIUM-04) AC-33'ün doküman katmanını etkilemez. Üç kopya
  (runtime modülü, `deployment.md` bounded blokları, helper içindeki
  bağımsız literaller) birbirinden türetilmez — tautoloji bilinçli olarak
  **engellenmiştir**.
- **SEC-H1 sınıfı key allowlist ile kapalı**: Next header kuralında `has`,
  `missing`, `locale`, `basePath` anahtarlarını kabul eder; bunlardan biri
  eklendiğinde production'da sıfır header emit edilir ama testler yeşil kalır.
  Wiring testi `Object.keys(rule)` tam olarak `["headers","source"]`, artifact
  oracle ise `["headers","regex","source"]` doğrular. Emit edilen beş header:
  `Content-Security-Policy`, `X-Frame-Options`, `X-Content-Type-Options`,
  `Referrer-Policy`, `Permissions-Policy` — `Strict-Transport-Security`
  **bilinçli olarak yoktur**.
- **`/_next/image` ayrı yanıt sınıfıdır**: Image Optimizer kendi CSP'sini
  `res.setHeader` ile yazar ve global kuralı ezer. Sessiz istisna bırakmak
  yerine `images.contentSecurityPolicy` ile **açıkça pinlendi**:
  `default-src 'self'; script-src 'none'; sandbox;` — global politikadan daha
  kısıtlayıcıdır. Bu yanıtlarda `frame-ancestors` kaybolur, ancak
  `X-Frame-Options: DENY` hayatta kalır, yani clickjacking kapalı kalır. Pin,
  artifact oracle tarafından `required-server-files.json` üzerinden geri okunur.
- **HSTS bilinçli emit edilmiş değil**: edge sahipliği, HTTP/HTTPS sorunları
  nedeniyle; deployment architecture'de kararlı.
- **Admin header'ları repository runtime'ı tarafından uygulanmaz**: admin
  layer'ı kendi header strategy'sini tanımlar.
- **CSP `'unsafe-inline'` içerir, script injection'a karşı korumaz**: dürüst
  beyan (`docs/test-reports/` evidence'ında açık).
